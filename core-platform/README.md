# Libro-Bot — Core Platform (Spring Boot)

Enterprise transactional core for Libro-Bot:
- **Stack:** Java 17 LTS, Spring Boot 3.3.x, MySQL 8.x, Flyway, Apache POI.
- **Responsibilities:** Owns all inventory, audit sessions, classification logic, report generation, multi-tenancy, and STOMP WebSocket push.
- **Status:** Scaffolding created in Phase 0; generation starts in Phase 1 Task 1.
